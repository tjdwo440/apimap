# 길찾기 거리 계산기

출발지와 도착지를 검색하고 자동차 도로 기준 이동 거리를 확인하는 한국어 웹앱입니다. 별도의 서버, Redis, API 키, 환경변수 또는 빌드 명령이 없는 정적 사이트입니다.

## 실행

`index.html`을 브라우저에서 열거나 정적 파일 서버로 제공하면 됩니다. 장소 검색과 경로 계산은 인터넷 연결이 필요합니다.

## Vercel 배포

1. 이 폴더의 파일을 GitHub 저장소에 올립니다.
2. Vercel에서 **Add New → Project**를 선택한 뒤 저장소를 Import 합니다.
3. 별도 빌드 설정이나 환경변수 없이 배포합니다. Vercel이 루트의 `index.html`을 정적 페이지로 제공합니다.

## 데이터 제공자

- 장소 검색: [Nominatim](https://nominatim.openstreetmap.org/)
- 자동차 경로 및 거리: [OSRM 공개 데모 서버](https://router.project-osrm.org/)
- 지도 링크 및 지도 데이터: [OpenStreetMap](https://www.openstreetmap.org/)

공개 데모 서비스는 사용량 제한 및 제공 정책이 있으며, 가용성이나 실시간 도로 상황을 보장하지 않습니다. Nominatim의 사용 정책에 따라 검색 요청을 최소화하도록 입력 검색에 지연 및 요청 간격 제한을 적용했습니다. 대량 트래픽이나 상용 서비스 규모로 운영할 때는 각 제공자의 최신 정책을 확인하고 적합한 호스팅 서비스를 사용하세요.
